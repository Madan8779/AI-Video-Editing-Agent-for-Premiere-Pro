MVP USER FLOW
1. Launch desktop app; first-run wizard checks Premiere/Creative Cloud, plugin version, FFmpeg, folders, model configuration, permissions, free disk space.
2. Select a local video (MP4/MOV) and choose Car Review, Travel Vlog, Educational Video or Shorts preset.
3. Probe media, detect silence/scenes, transcribe selected language (Kannada/English where supported), show timestamped transcript and proposed cuts.
4. Display editable timecoded JSON edit plan with source path, rationales, durations, confidence and before/after preview strategy. Preserve original sources.
5. When Premiere is connected, inspect active project/sequence; explicitly ask user approval; create a duplicate/new sequence and apply only supported cuts/insertions, with operation log and recovery strategy. If editing API unavailable, export a clearly labeled interoperable edit-decision file or supported import alternative rather than falsely claiming edits were applied.
6. Generate SRT caption file, optionally import it with a verified supported method; background-music placement and transitions are later gated features.
7. Show export options. Require approval for export; execute only if verified API support exists, otherwise guide user through Premiere export. Verify output media with ffprobe where programmatically produced.
